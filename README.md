# Advanced Signal Processing (Προηγμένες Τεχνικές Επεξεργασίας Σήματος)

Repository for coursework, laboratory exercises, and projects for the **Advanced Signal Processing** course at the **University of Ioannina, Department of Informatics and Telecommunications**.

## 📚 Course Structure & Lab Branches
Each laboratory assignment and project series is maintained in an isolated branch:
- [`lab-01`](https://github.com/ntontouu/Advanced-Signal-Processing/tree/lab-01): 1η Σειρά Εργαστηριακών Ασκήσεων — Μαθαίνοντας στο MATLAB (Πίνακες, Συναρτήσεις, Αρχεία, Γραφικά).
- `lab-02`: 2η Σειρά Εργαστηριακών Ασκήσεων — Σήματα Διακριτού Χρόνου, Απεικόνιση, Διαχείριση Αρχείων & Βασικά Είδη Σημάτων *(Upcoming)*.
- `lab-03`: 3η Σειρά Εργαστηριακών Ασκήσεων — Απόκριση Συστήματος & Συνέλιξη *(Upcoming)*.

## 🛠️ Environment & Prerequisites
- **Environment:** MATLAB or [GNU Octave](https://octave.org/)
- **Version Control:** Git & GitHub
