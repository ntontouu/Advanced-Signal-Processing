## 🔍 Περιγραφή Ασκήσεων
- **Ασκήσεις Πινάκων (Ασκήσεις 1, 2):** Υπολογισμός μέσης τιμής πίνακα, μετατροπή θερμοκρασιών Κελσίου/Φαρενάιτ και μορφοποιημένη εκτύπωση με `fprintf`.
- **Ασκήσεις Συναρτήσεων (Ασκήσεις 3, 4, 5):** Συναρτήσεις υπολογισμού μέσης τιμής (`matrix_mean`), εύρεσης μέγιστου/ελάχιστου (`pms4`) και πλήθους θετικών/αρνητικών στοιχείων (`pms5`).
- **Ασκήσεις Αρχείων (Ασκήσεις 6, 7, 8):** Εγγραφή και ανάγνωση ακεραίων (`numbers.txt`), καθώς και εξαγωγή δεδομένων θερμοκρασιών με στηλοθέτη (`temperatures.txt`).
- **Ασκήσεις Γραφικών (Ασκήσεις 9, 10):** 
  - Προσομοίωση φθίνουσας αρμονικής ταλάντωσης με εκθετική απόσβεση πλάτους.
  - Σύνθεση ταλαντώσεων και απεικόνιση του φαινομένου του διακροτήματος με χρήση `subplot`.

## 🛠️ Δομή Αρχείων

- `lab_01/ΝΤΟΝΤΟΥ_ΠΤΕΣ1.pdf`: Η τελική αναφορά της εργαστηριακής σειράς.
